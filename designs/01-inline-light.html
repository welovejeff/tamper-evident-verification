INTEGRATION — add the light to your app ~3 lines either stack

NODE / any static frontend

<!-- 1. one script tag -->
<script type="module">
  import { mountTamperSignal }
    from "/badge/light.js";

  // 2. one init call — same args as renderReceiptBadge()
  mountTamperSignal(
    document.querySelector("header"),
    "/receipts/chain.json"   // pubKeyHex optional; falls back to chain.json key
  );
</script>

REACT one-liner

<TamperSignal chain="/receipts/chain.json" />

Verification runs entirely in the viewer's browser (Web Crypto Ed25519). The light re-checks every signature and every hash link on page load — no server trust required.

PYTHON — Flask

# 1. serve your receipts directory as-is
app = Flask(__name__, static_folder="receipts",
            static_url_path="/receipts")

# 2. one include in your layout template
{% include "tamper_signal.html" %}

PYTHON — FastAPI

# 1. mount the receipts dir written by your pipeline
app.mount("/receipts",
          StaticFiles(directory="receipts"))

# 2. drop the include into your Jinja layout
{% include "tamper_signal.html" %}

Your pipeline already writes receipts/chain.json + per-stage receipt files; the include is a 1 KB snippet that loads light.js pointed at that directory.
